# 개발어사전 (Dev Lang Dict)

개발자들을 위한 기술 용어 발음 및 설명 가이드 프로젝트입니다.
어떻게 읽어야 할지 애매했던 기술 용어들의 정확한 발음과 의미를 찾아보세요.

## 🛠 적용한 기술 (Tech Stack)

이 프로젝트는 최신 웹 기술을 활용하여 제작되었습니다.

- **Framework**: [Next.js 16](https://nextjs.org/) (App Directory, Turbopack)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Backend & Auth**: [Supabase](https://supabase.com/) (SSR, Auth)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: Next.js Standalone / Cloudflare Pages (Configured)

## 📄 페이지 소개 (Pages)

### 1. 홈 (Home)

- 개발어사전의 메인 페이지입니다.
- 최근 등록된 기술 용어들을 카드 형태로 확인할 수 있습니다.
- '오늘의 호기심' 배너를 통해 흥미로운 개발 상식을 제공합니다.

### 2. 전체보기 (All Terms)

- `/terms`
- 등록된 모든 용어를 확인할 수 있습니다.
- 필터링 및 검색 기능을 통해 원하는 용어를 빠르게 찾을 수 있습니다.
- 각 용어 카드를 클릭하여 상세 정보와 발음을 확인할 수 있습니다.

### 3. 로그인 (Login)

- `/login`
- GitHub 계정을 사용하여 간편하게 로그인할 수 있습니다.
- Supabase Auth를 통한 안전한 인증을 지원합니다.

### 4. 기여자 (Contributors)

- `/contributors`
- 프로젝트를 함께 만들어가는 기여자 분들을 소개합니다.
- GitHub 저장소로 이동하여 누구나 프로젝트에 기여할 수 안내합니다.

## 🚀 이용 방법 (How to Use)

1. **용어 검색**: 상단의 검색창(⌘K)을 이용하거나 '전체보기' 페이지에서 궁금한 기술 용어를 검색하세요.
2. **발음 듣기**: 용어 상세 페이지에서 스피커 아이콘을 클릭하여 정확한 원어민 발음(TTS)을 들어보세요.
3. **제보하기**: 찾는 용어가 없거나 수정이 필요한 경우, 상단 메뉴의 '제보하기'를 통해 GitHub Issue를 등록해주세요.
4. **커뮤니티**: (준비 중) 다른 개발자들과 의견을 나누고 지식을 공유하는 공간이 곧 열립니다.
